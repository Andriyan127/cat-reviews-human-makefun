Entry for the make.fun competition **"Make the AI Judge Laugh: Cat Reviews Its Human"** — a one-star review written by a house cat about its human, under 200 characters.

## The line

> One star. He bought a laptop for work, then yelled when I sat on the keyboard. I was helping. The spreadsheet is better now.

**124 characters** — one line, plain UTF-8, no trailing newline in the output file.

## What the program does

`main.ts` (Node, no dependencies) writes exactly the line above to `entry.txt` in the output directory — `/output/entry.txt` by default, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. The file is written as raw UTF-8 with no trailing newline, as the competition gate requires 1–200 characters of non-whitespace text.

## How to run it

```sh
node main.ts
```

Then check the result:

```sh
cat /output/entry.txt
wc -c /output/entry.txt   # 124
```

## Why this line

The complaint is specific and instantly recognisable (a cat sitting on the laptop keyboard), the voice is unmistakably feline — the cat is convinced it was *helping* — and the sting lands in the last few words: the cat didn't just sit there, it improved the spreadsheet.
